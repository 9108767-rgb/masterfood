Мобильная версия конструктора

Тот же адаптивный макет в окне 390 × 844 (iPhone 14). Ниже — решения, которые применяются только на узком экране.

390 × 844 · прокручивается внутри рамки

Что меняется на телефоне

  • Шапка сжимается: остаются логотип, кнопка «Меню» и телефон; навигация уходит в выпадающее меню.
  • Даты доставки — горизонтальная лента с прокруткой, чипы крупные (44 px), выбрано 3 из 3–10.
  • В меню дня видна только колонка выбранного рациона; кнопка «Сравнить категории» разворачивает остальные две.
  • Дни свёрнуты в аккордеон: открыт один день, чтобы не листать 120 карточек.
  • Блюдо — компактная строка: название, вес, ккал, цена и «Заменить»; замена открывается в полноэкранном листе снизу.
  • Итог закреплён внизу экрана: дней, сумма и кнопка «Оформить»; он не перекрывает контент (учтён safe-area).
  • Форма заказа — одноколоночная, поля ввода 48 px, клавиатура не перекрывает кнопку оплаты.
  • Шаги 1–4 показаны без подписей — только номера и активный шаг.

Проверки

  • Тап-зоны не меньше 44 × 44 px.
  • Нет горизонтальной прокрутки страницы — только внутри ленты дат.
  • Контраст текста не ниже 4.5:1.
  • Вес страницы: один HTML + один CSS + один JS, без тяжёлых библиотек.
